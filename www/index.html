Production Infrastructure

Static sites, shipped in one command.

A production-ready Nginx static HTML server orchestrated by Docker Compose. Pure immutable images, hardened security headers, no volumes, and optional SSL.

Get Started Deploy to VPS
Terminal 
$ git clone git@github.com:hydrokat/docker-compose-html.git
$ cd docker-compose-html
$ docker compose up -d --build
✔ Container docker-compose-html-web Started [0.2s]
→ Open http://localhost

Architectural Principles

Engineered for deterministic static website hosting with zero operational overhead.

One-Command Run

Single docker compose up spins up a fully isolated, production-grade Nginx web container ready for traffic.

Immutable Images

No bind mounts or volume drift. Content is baked directly into the image at build time for strict environment parity.

SSL / TLS Ready

Toggle HTTPS on demand with pre-configured TLS 1.2/1.3, HTTP/2, 301 redirects, and opt-in HSTS hardening.

VPS Optimized

Designed to run cleanly on low-cost virtual private servers (Ubuntu, Debian) with minimal resource consumption.

How It Works

Three straightforward steps to build and host your web application.

  1. 1

    Clone the Repository

    Pull the repository onto your local workstation or production Linux VPS server.

  2. 2

    Place Your HTML in www/

    Drop your static HTML, CSS, client-side JS, images, and fonts directly into the www/ directory.

  3. 3

    Build & Run Container

    Execute docker compose up -d --build. Nginx serves your content immediately on ports 80 and 443.
