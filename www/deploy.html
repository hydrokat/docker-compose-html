VPS Deployment Guide

A complete walkthrough for deploying a live, production-grade static website to any Linux VPS provider (Hetzner, DigitalOcean, Linode, AWS Lightsail) running Ubuntu 24.04 LTS.

Standard Production Baseline

This guide assumes Ubuntu 24.04 LTS, domain example.com, and official Docker Engine repositories.

1. DNS & Domain Setup

Point your domain's A (and optional AAAA) records to your server's public IP address:

Terminal 
# Verify DNS resolution before proceeding
dig +short example.com

2. Server Hardening

Configure a non-root sudo user, SSH key authentication, and the UFW firewall:

Terminal 
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow OpenSSH
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw enable

3. Install Docker Engine & Compose

Install the official Docker repository packages:

Terminal 
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
# Add Docker's official GPG key and repository
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
sudo chmod a+r /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

4. Deploy Repository

Clone the website codebase to /opt/site:

Terminal 
sudo git clone git@github.com:hydrokat/docker-compose-html.git /opt/site
cd /opt/site
sudo docker compose up -d --build

5. Production HTTPS with Let's Encrypt

Obtain certificates via standalone Certbot, copy to the build context, and rebuild:

Terminal 
# Temporarily stop web container to release port 80 for ACME challenge
sudo docker compose down
sudo certbot certonly --standalone -d example.com -d www.example.com

# Copy certificates into project
sudo cp /etc/letsencrypt/live/example.com/fullchain.pem docker/nginx/certs/
sudo cp /etc/letsencrypt/live/example.com/privkey.pem docker/nginx/certs/
sudo chmod 600 docker/nginx/certs/privkey.pem
