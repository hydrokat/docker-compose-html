Usage Guide

Everything you need to know about developing, modifying, testing, and managing static websites with docker-compose-html.

Prerequisites

Before running the project, ensure you have the following installed on your machine:

  • Docker Engine (v20.10 or higher)
  • Docker Compose v2 plugin (docker compose)
Terminal 
docker compose version

Quick Start

Start serving static HTML with a single command:

Terminal 
git clone git@github.com:hydrokat/docker-compose-html.git
cd docker-compose-html
docker compose up -d --build

Navigate to http://localhost in your web browser.

Updating Content

Because static files are baked directly into the Docker image, changes in www/ require a rebuild to take effect:

Terminal 
docker compose up -d --build
Immutable Image Architecture

By avoiding host volume mounts, your containerized site runs identically in development and production.

Port Configuration

By default, host ports 80 and 443 are published. If you encounter port conflicts, you can edit docker-compose.yaml to map alternative host ports:

docker-compose.yaml 
ports:
  - "8080:80"
  - "8443:443"

Enabling Local SSL

To enable HTTPS for local development:

  1. Generate a self-signed certificate into docker/nginx/certs/.
  2. Uncomment the SSL server and redirect blocks in docker/nginx/nginx.conf.
  3. Comment out the standalone HTTP server block.
  4. Rebuild: docker compose up -d --build.
Private Key Security

Certificates are built into the image. Never push images with private keys to public registries.

Testing & Verification

Run the automated test suite to verify configuration, endpoint responses, and optional SSL:

Terminal 
# Run HTTP smoke tests
./tests/smoke.sh

# Run SSL smoke tests
SMOKE_SSL=1 ./tests/smoke.sh

Troubleshooting

Common operational issues and how to resolve them:

  • Port 80/443 already allocated: Check existing services with docker ps or lsof -i :80.
  • Nginx syntax errors: Run docker compose exec web nginx -t to validate your configuration.
  • View container logs: Run docker compose logs -f web.
